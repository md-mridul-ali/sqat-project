# 🏥 MediCare – Software Quality Assurance & Testing Project

## 📌 Project Overview

**MediCare** is a healthcare service platform designed to improve emergency medical access, telemedicine, digital medical record management, and healthcare support for rural areas and senior citizens.

This project was developed as part of the **Software Quality Assurance and Testing (SQAT)** course at **American International University-Bangladesh (AIUB)**.

The main focus of this project is creating a comprehensive **Software Test Plan**, including:

* Functional Testing
* Non-Functional Testing
* Security Testing
* Performance Testing
* Payment Testing
* Test Case Design
* QA Documentation

---

## 🎯 Objectives

The project aims to solve several healthcare-related problems:

* Easy access to digital medical records
* Emergency ambulance support
* Remote doctor consultation (Telemedicine)
* Healthcare support for rural areas
* Senior citizen home healthcare
* Emergency OTP-based login system
